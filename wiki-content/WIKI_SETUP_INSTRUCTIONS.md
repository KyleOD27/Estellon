# GitHub Wiki Setup Instructions

## How to Create Your Wiki Pages

I've created wiki-formatted versions of your documentation. Here's how to add them to your GitHub Wiki:

### Step 1: Access Your Wiki
Go to: https://github.com/KyleOD27/Estellon/wiki

### Step 2: Create Each Page

For each `.md` file in the `wiki-content/` folder:

1. **Click "New Page"** in your GitHub Wiki
2. **Copy the filename** (without .md extension) as the page title
   - `Home.md` → Title: "Home"  
   - `Character-Voices.md` → Title: "Character Voices"
   - `Campaign-Overview.md` → Title: "Campaign Overview"
   - etc.

3. **Copy and paste** the entire content from each file
4. **Click "Save Page"**

### Step 3: Pages to Create

I've prepared these wiki pages for you:

#### Essential Pages (Create First)
- **Home** - Main wiki homepage with navigation
- **Character Voices** - AI voice features and audio samples  
- **Campaign Overview** - Setting, themes, and faction overview
- **Getting Started** - GM guide for running the campaign
- **Ser Elara Vance** - Example character profile

#### Additional Pages (Create as Needed)
You can create more pages by copying content from your existing files:
- Character profiles for Kael, Brennis, Pellor, etc.
- Story pages for Prologue, Act I, Act II, Act III
- Game mechanics pages
- Setup guides for ElevenLabs integration

### Step 4: Customize Links

After creating pages, the `[[Page Name]]` links will automatically work in your GitHub Wiki. You can also:
- Edit any page to customize content
- Add more internal links using `[[Page Title]]` syntax
- Link to files in your repository using full GitHub URLs

### Step 5: Organize Your Sidebar

In your GitHub Wiki, you can create a "Sidebar" page to add custom navigation that appears on all pages.

## Wiki Features

GitHub Wiki automatically provides:
- **Search functionality** across all pages
- **Edit history** for each page  
- **Internal linking** with `[[Page Name]]` syntax
- **Markdown rendering** with full GitHub Flavored Markdown support
- **Navigation breadcrumbs** and page listings

## Tips

- **Start with Home page** - This becomes your wiki's main entry point
- **Use consistent naming** - Keep page titles simple and clear
- **Internal links** - Use `[[Page Name]]` to link between wiki pages
- **External links** - Use full URLs to link back to repository files
- **Images** - Upload images to your repository and link with full GitHub URLs

Your wiki will then be accessible at: https://github.com/KyleOD27/Estellon/wiki
